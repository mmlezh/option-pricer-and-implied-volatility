# Прайсер европейских опционов и implied volatility

Учебный проект на C++20.

Цель: консольное приложение для оценки европейских опционов по модели Black-Scholes-Merton и восстановления implied volatility по заданной цене опциона.

## Планируемый функционал

Целевая версия проекта предполагает следующие возможности:

| Возможность | Описание |
|---|---|
| Оценка опционов | Расчёт цены европейских call/put с постоянной непрерывной дивидендной доходностью |
| Греки | Расчёт Delta, Gamma, Vega, Theta и Rho для анализа чувствительности цены |
| Implied volatility | Восстановление IV методом бисекции и защищённым методом Ньютона с резервным шагом бисекции |
| Диагностика | Проверка входных данных и границ цены; статус расчёта IV, число итераций, ошибка цены и число резервных шагов |
| Консольный интерфейс | Команды `price`, `greeks` и `iv` с параметрами пользователя |
| Пакетные расчёты | Чтение и запись CSV, сохранение идентификаторов и порядка результатов, обработка ошибок отдельных записей |
| Параллельное исполнение | Последовательная и многопоточная обработка пакетов с одинаковыми численными результатами |

Вычислительное ядро планируется отделить от консольного интерфейса и файлового ввода-вывода. Корректность будет проверяться независимыми эталонами и математическими свойствами, производительность — бенчмарками. Выбранный объём проекта ограничен европейскими опционами: американские и экзотические опционы в него не входят. Это план развития проекта, а не перечень обязательных функций инфраструктурного ДЗ; отдельное экспериментальное исследование в объём ДЗ не входит.

## Что реализовано сейчас

**В этой версии реализован минимальный прайсер и инженерная инфраструктура.**

- Функция `option_pricer::price` для цены европейских call/put по BSM с учётом дивидендной доходности.
- Типы `OptionParameters`, `PricingResult` и `Status`; проверка входных параметров, обработка T=0 и sigma=0, диагностика недопустимых численных значений.
- Демонстрационная программа `pricing_demo`, рассчитывающая call и put на фиксированных параметрах.
- Четыре теста GoogleTest: эталонные цены, put-call parity, граничные случаи и некорректные данные.
- Google Benchmark для измерения времени расчёта call и put.
- Сборка CMake, запуск тестов через CTest, генерация Doxygen и инструкции агенту в `AGENTS.md`.
- Конфигурация GitHub Actions для сборки, тестов, бенчмарка, генерации и публикации документации. Удалённый запуск CI и публикация Pages для этой версии пока не подтверждены.

## Сборка и запуск

Поддерживаемое окружение: Linux, GCC 12+ с C++20, CMake 3.20+, Make и Doxygen. Сборка на Windows/macOS отдельно не проверена. В Ubuntu установите инструменты:

```bash
sudo apt-get update
sudo apt-get install -y g++ cmake make doxygen
```

При первой сборке выполните из папки проекта две команды:

```bash
cmake -S . -B build -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Release
make -C build
```

Запуск демонстрации:

```bash
./build/pricing_demo
```

Проверки и документация запускаются отдельно:

```bash
# Тесты
ctest --test-dir build --output-on-failure

# Бенчмарк
./build/pricing_bench --benchmark_min_time=0.02s

# HTML-документация
make -C build docs
```

Ожидаемый вывод при S=K=100, T=1, r=0.05, q=0, sigma=0.2:

```text
call: 10.4505835722
put: 5.57352602226
```

Демонстрация использует фиксированные параметры из `app/main.cpp`; аргументы командной строки не нужны. Чтобы вызвать функцию со своими параметрами, заполните `OptionParameters` и проверьте `PricingResult::status` перед использованием цены.

CMake закрепляет GoogleTest 1.15.2 и Google Benchmark 1.9.1 версиями и SHA-256 и проверяет HTTPS-сертификаты. Doxygen требуется уже при конфигурации CMake: если он не установлен, CMake сообщит об этом сразу. После генерации откройте локальную документацию: `build/docs/html/index.html`.
